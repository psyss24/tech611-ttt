### devops
devops -> to maintain the infrastructure that developers make use of to deploy their applications; concerned with reliability, security, automation, logging. it is an approach, it can be a mindset, culture, etc.


a developer/swe is not concerned with:
- which server runs my application?
- how do i deploy my code?
- has the environment im using got the correct variable?

### on premises vs cloud
on premises -> physically owned
cloud -> on demand deliver of computing power, database, storage, application services; these are rented to you

### cloud deployment models

public -> multi tenant cloud is shared by different individuals/organisations
private cloud -> access is dedicated to one org
- can be run with no internet connection
hybrid -> mix of public cloud + on prem
multi cloud -> using multiple cloud providers

## Advantages / Disadvantages of the cloud
### advantages
- can access resources anywhere on demand
- bypass upfront cost of owning server equipment 
- not responsible for managing the server
### disadvantages
- prone to server outage (redundancy can mitigate this)
- need an internet connection for public cloud
