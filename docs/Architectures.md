# Architectures

## 2 Tier Deployment
- One VM for the app and another VM for the Database

## 3 Tier Deployment
- One VM for the app and another VM for the Database, like 2 tier
- but need an additional presentation tier that is ran in the user's browser
- 

## Microservice
- One VM for each service, can scale each service independently
- can choose specific language, framework for each service
- increased complexity in deployment
